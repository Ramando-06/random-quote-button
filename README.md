# Color Palette Generator

A simple static web app that generates harmonious color palettes from a base color.

## Features

- Pick a base color or generate a random one
- Harmony types: complementary, analogous, triadic, split complementary, tetradic, monochromatic
- Click any swatch to copy its hex code

## Run locally

Open `index.html` in your browser, or use a local server:

```bash
npx serve .
```

## Deploy to GitHub Pages

1. Create a new GitHub repository and push this project.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save. Your site will be live at `https://<username>.github.io/<repo-name>/`.

No build step is required — GitHub Pages serves the static files directly.
